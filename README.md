# Welcome to PIT Policies API project
This is the primary code repository for PIT Policies API.

The Production Insurance Tools Policies API project supports the Ministry of Agriculture suite of applications developed to help farmers manage the risks associated with crop damage or loss due to naturally occurring perils.

## Technologies used

* [Java](https://www.java.com/en/)

### CI/CD for DEV/TEST/PROD Deployments

The PIT Common project is built and deployed via Github actions and the Polaris Pipeline.
